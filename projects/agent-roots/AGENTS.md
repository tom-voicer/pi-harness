# agent-roots project instructions

## After any code change

After modifying any file in this project (src/*.ts, package.json, tsconfig.json, bin/roots), review `README.md` and update it if the change affects:

- **Architecture** — new files, changed flow, different dependencies
- **Design decisions** — new rationale, changed approaches
- **Gotchas** — new lessons learned, pitfalls discovered
- **API/CLI** — new flags, changed defaults, removed options
- **Limitations** — newly fixed or newly discovered constraints
- **Future ideas** — items implemented or new roadmap entries

If the README needs updating, do it in the same turn — don't ask permission. The README is the context document for future coding agents working on this project; keeping it current is as important as the code itself.
